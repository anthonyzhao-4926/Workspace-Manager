# Cursor Workspace

把常用项目组合成 Workspace，在侧栏里一键打开、编辑或删除。适合同时要打开多个仓库、又不想每次手动「将文件夹添加到工作区」的人。

## 它能做什么

- 把多个项目收进一个 Workspace，下次点一下就能打开
- 当前正在用的 Workspace 会置顶高亮，方便继续加项目
- 删除只去掉 Workspace 本身，项目文件夹还在

## 安装

1. 拿到插件的 `.vsix` 文件
2. 打开 Cursor，命令面板搜索 **Install from VSIX…**
3. 选中该文件完成安装
4. 重启 Cursor（或重新加载窗口）

装好后，左侧活动栏会出现 **Cursor Workspace** 图标。

## 开始使用

第一次使用前，先告诉插件去哪里找项目：

1. 打开设置，搜索 `Cursor Workspace`
2. 在 **Project Folders** 点「选择路径」添加目录
3. 插件只会读取这些目录下的**第一层文件夹**作为候选项目

候选项目不够时，新建/编辑页里也可以临时从磁盘选文件夹。

## 日常操作

侧栏打开 **Cursor Workspace**：

| 操作 | 怎么做 |
|------|--------|
| 新建 | 点标题栏 **+**，起名后勾选项目，再「创建」或「创建并打开」 |
| 打开 | 点列表里的 Workspace，会在**新窗口**打开，当前窗口不受影响 |
| 给当前 Workspace 加项目 | 点标题栏 **★**，或点置顶高亮的那一项 |
| 改名称 / 改项目 | 点该行的铅笔 |
| 删除 | 点该行的垃圾桶，确认后删除（不会删项目目录） |
| 看文件放在哪 | 命令面板搜索 **打开 Workspace 存放目录** |

新建或编辑时：

- 用名称筛选项目，左侧勾选，右侧查看已选
- 点 **选择文件夹** 可以加入不在候选目录里的项目
- 点 **刷新** 重新扫描候选项目


## 设置

在 Cursor 设置里搜索 `Cursor Workspace`：

| 设置 | 说明 |
|------|------|
| **Project Folders** | 点「选择路径」添加；列表中可删除；只扫第一层文件夹 |
| **Workspace Storage Path** | Workspace 文件存放位置。首次使用自动填入插件默认路径，也可改成其他目录 |

## 常见问题

**侧栏是空的？**  
先配置 Project Folders，再点 **+** 新建第一个 Workspace。

**找不到某个项目？**  
确认它在配置目录的第一层，或用「选择文件夹」临时加入。需要最新列表时点刷新。

**删错了会怎样？**  
只删除 Workspace 文件，项目代码不会被删。
