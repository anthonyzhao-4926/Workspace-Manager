# Workspace Manager

把经常一起打开的几个项目记成一组。下次在左侧点一下，就会在新窗口里一起打开。

适用于 VS Code 和 Cursor。适合要同时看多个项目、又不想每次自己把文件夹加进工作区的人。

## 你可以做什么

- 把多个项目收成一组，下次点一下打开
- 正在用的那一组会排在最上面并高亮，方便继续往里加项目
- 删掉某一组时，只是去掉这个记录，项目文件夹还在

## 安装

1. 准备好扩展安装包（`.vsix`）
2. 打开命令面板，搜索 **从 VSIX 安装**
3. 选中安装包，完成安装
4. 左侧如果没有出现图标，重新加载窗口

macOS 用 `Cmd+Shift+P` 打开命令面板，Windows 和 Linux 用 `Ctrl+Shift+P`。

装好后，左侧活动栏会出现 **Workspace Manager**。

## 第一次使用

先告诉它你的项目放在哪些文件夹里：

1. 打开设置，搜索 `Workspace Manager`
2. 在 **Project Folders** 里点「选择路径」，选中放项目的文件夹
3. 这个文件夹里能直接看到的项目会出现在列表中。放在更里面的目录不会出现

列表里没有的项目，新建或编辑时也可以当场从电脑里选一个文件夹加进去。

## 怎么用

点左侧 **Workspace Manager**：

| 你想做的事 | 怎么做 |
|---|---|
| 新建一组 | 点标题栏 **+**，起个名字，勾选项目，再点「仅创建」或「创建并打开」 |
| 打开一组 | 点列表里的名字。会新开一个窗口，当前窗口保持不动 |
| 往当前这组里加项目 | 点标题栏 **★**，或点最上面高亮的那一项 |
| 改名字或换项目 | 点这一行的铅笔 |
| 删掉一组 | 点这一行的垃圾桶并确认。项目本身还在 |

新建或编辑时：

- 在搜索框里按名字找项目，左边勾选，右边是已经选中的
- 点 **选择文件夹**，可以把上面那些目录里没有的项目也加进来
- 点 **刷新**，重新看看有没有新项目

## 设置

打开设置，搜索 `Workspace Manager`：

| 设置 | 什么时候要改 |
|---|---|
| **Project Folders** | 你的项目都放在哪些文件夹。点「选择路径」添加，不需要的可以删掉。只会列出里面直接看到的项目 |
| **Workspace Storage Path** | 这些分组保存在哪。第一次使用会自动填好，平时不用改。想换个地方保存时再改 |

想打开保存它们的文件夹：打开命令面板，搜索 **打开 Workspace 存放目录**。

## 常见问题

**左侧是空的？**  
先在设置里加上 Project Folders，再点 **+** 新建第一组。

**某个项目找不到？**  
看它是不是就在你填的那个文件夹里面，而不是更里层的子目录。也可以在新建页面点「选择文件夹」直接加。列表不是最新时，点刷新。

**不小心删了一组？**  
删掉的是这一组的记录，项目里的代码还在。需要的话重新勾选，再建一组。
